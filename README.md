Simple 2D Canvas Editor

A lightweight browser-based 2D canvas editor built with React,
Fabric.js, and Firebase Firestore.

Users can create a canvas, add and edit shapes and text, draw with a pen
tool, and save their work. Each canvas is stored in Firestore and can be
reopened using its unique URL.

Getting Started

1. Clone the repository

git clone https://github.com/ojasvirastogi/canva.git
cd canva

2. Install dependencies

npm install

3. Configure Firebase

Create a Firebase project and enable Cloud Firestore.

Create a .env file in the project root:

VITE_FIREBASE_API_KEY=your_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=your_project_id
VITE_FIREBASE_STORAGE_BUCKET=your_project.firebasestorage.app
VITE_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
VITE_FIREBASE_APP_ID=your_app_id

Do not commit .env to GitHub.

4. Configure Firestore Rules

For this assignment/demo, the application uses an unauthenticated
Firestore setup:

rules_version = '2';

service cloud.firestore {
  match /databases/{database}/documents {
    match /canvases/{canvasId} {
      allow read, write: if true;
    }
  }
}

These rules are intentionally open for the assignment. A production
application should use Firebase Authentication and restrictive
security rules.

5. Start the development server

npm run dev

Open the local URL shown by Vite, usually:

http://localhost:5173

How It Works

Creating a Canvas

From the home page, clicking Create New Canvas creates a new
Firestore document in the canvases collection.

The Firestore document ID becomes the canvas ID:

/canvas/{canvasId}

The application then navigates to that URL.

Editing

Fabric.js manages the canvas and its objects.

Supported objects include:

Rectangle

Circle

Text

Freehand paths

Fabric.js also handles:

Selection

Movement

Scaling

Rotation

Text editing

Saving

When the user clicks Save, the Fabric.js canvas is serialized using:

canvas.toJSON()

The resulting canvas data is stored in Firestore:

canvases
└── {canvasId}
    ├── canvasData
    ├── createdAt
    └── updatedAt

Loading

When a canvas URL is opened, the application:

Reads the canvasId from the URL.

Fetches the corresponding Firestore document.

Reads canvasData.

Restores the objects using Fabric.js loadFromJSON().

This allows the same canvas to be reopened from the same URL.

Design Decisions

Fabric.js

Fabric.js handles the complex canvas interactions instead of
implementing object manipulation from scratch.

Firestore

Firestore provides simple document-based persistence for the serialized
canvas state.

URL-Based Canvas IDs

Using the Firestore document ID as the URL parameter makes each canvas
directly accessible:

/canvas/{canvasId}

No Authentication

Authentication was intentionally omitted because it is not required for
this assignment.

For a production version, authentication and per-user access control
should be added.

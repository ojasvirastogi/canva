Simple 2D Canvas Editor

A lightweight browser-based 2D canvas editor built with React,
Fabric.js, and Firebase Firestore.

Users can create a canvas, add and edit shapes and text, draw with a pen
tool, and save their work. Each canvas is stored in Firestore and can be
reopened using its unique URL.

Features

Unique canvas ID generated by Firestore

URL-based canvas access

Rectangle tool

Circle tool

Text tool

Freehand pen tool

Select and move objects

Resize objects

Rotate objects

Delete selected objects

Delete/Backspace keyboard support

Change object colors

Change text font size

Save canvas state to Firestore

Load previously saved canvas state

Save status indicator

Loading and error states

Ctrl + S / Cmd + S save shortcut

Responsive interface

Getting Started

1. Clone the repository

git clone https://github.com/ojasvirastogi/canva.git
cd canva

2. Install dependencies

npm install




Deployment

The application can be deployed using Vercel.

Vercel Configuration

Build settings:

Framework: Vite
Build Command: npm run build
Output Directory: dist

Add the Firebase environment variables in:

Vercel
→ Project
→ Settings
→ Environment Variables

Add:

VITE_FIREBASE_API_KEY
VITE_FIREBASE_AUTH_DOMAIN
VITE_FIREBASE_PROJECT_ID
VITE_FIREBASE_STORAGE_BUCKET
VITE_FIREBASE_MESSAGING_SENDER_ID
VITE_FIREBASE_APP_ID
